# QA Templates

Welcome to the **QA Templates** library.

This folder contains practical, reusable templates used throughout the Software Testing Life Cycle (STLC). These templates are designed for manual testers, QA engineers, SDETs, and AI-assisted QA workflows.

## Purpose

The goal of this collection is to:

- Standardize QA documentation
- Improve test planning and execution
- Reduce documentation effort
- Increase consistency across projects
- Provide production-ready templates for real-world use

# Template Standards

Each template includes:

- Objective
- Scope
- Preconditions
- Steps
- Expected Result
- Actual Result
- Status
- Owner
- Priority
- Notes

---

# Best Practices

- Keep templates simple and reusable.
- Update documentation with every release.
- Maintain version history.
- Review templates regularly.
- Use AI to accelerate documentation while validating all outputs.
